# PRISMA · Adaptive Perspective & Persona Engine

**Make perspectives comparable without mistaking representation for reality.**

PRISMA is a standalone, model-neutral method for documentary reconstruction, clearly labeled persona simulation, fictional character exploration, structured disagreement, and audience hypotheses. It adapts the representation to the field. It never acquires the authority of a source, a person, or an author's canon.

[Start with the canonical method](PRISMA.md#first-use) · [Português](README.pt-BR.md) · [Architecture](ARCHITECTURE.md) · [Adapter contract](ADAPTER_CONTRACT.md) · [Public boundary](PUBLIC_BOUNDARY.md) · [Validation](docs/FIRST_RELEASE_AND_VALIDATION.md)

| Need | Mode |
|---|---|
| Reconstruct a documented argument | Lens |
| Explore a fictionalized voice, expressly requested | Mask |
| Compare perspectives and disagreement | Table |
| Explore a consented personal mirror | Mirror |
| Find blind spots and alternative hypotheses | Counterproof |
| Test characters within fictional canon | World |
| Explore plausible audience readings | Reception |

**First use:** provide `PRISMA.md` to an AI with access to the source, or attach the verified offline method ZIP if retrieval is unavailable. Explain the work, sources, authority and desired contrast. No automatic installation, independent agents, tool access, or writeback follows. The reference gate is deterministic and deliberately does not generate speech or decide truth.
