# PRISMA · Motor Adaptativo de Perspectivas e Personas

**Coloque perspectivas em relação sem confundir representação com realidade.**

PRISMA é um método independente para reconstrução documental, simulação rotulada, exploração de personagens, dissenso e hipóteses de recepção. Adapta a configuração ao campo, não os fatos. A obra, a pessoa e a fonte soberana conservam suas autoridades.

[Entrada canônica (inglês)](PRISMA.md#first-use) · [Guia em português](docs/GUIA.pt-BR.md) · [English](README.md) · [Limites públicos](PUBLIC_BOUNDARY.md)

Use Lente para argumentos documentados; Máscara para ficção expressamente solicitada; Mesa para comparar perspectivas; Espelho mediante consentimento e fonte apropriada; Contraprova para testar falhas; Mundo para personagens e cânone; Recepção para hipóteses de leitura. Não é necessário montar uma mesa para uma pergunta simples.
