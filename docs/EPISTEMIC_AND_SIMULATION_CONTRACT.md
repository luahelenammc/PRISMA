# Epistemic and simulation contract

For each contribution, carry its mode, source locator(s), evidence label, uncertainty/limits and whether it is candidate-only. A documented source can support a reconstruction, not an invented quotation. A supported interpretation explains its inference; a hypothesis identifies conditions and uncertainty; fiction is explicitly labeled. Unverified evidence remains unverified. Insufficient basis must not generate named factual assertions. Verify source attribution, chronology, allowed knowledge, claims and privacy before emitting. Ask whether the difference in perspectives changes the decision; preserve disagreement when material and avoid pretend unanimity. A one-model table is a single-model comparison, not independent validation. The reference gate has no access to the truth of source declarations; its result cannot replace source inspection.
